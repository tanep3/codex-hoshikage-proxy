# MCP操作の確認画面 — 改訂後の利用者向け説明

2026-09-17。設計中の説明書。まだ常駐環境へ反映していません。APIの項目名は[接続契約案](mcp-approval-full-fix-api.ja.md)を参照してください。

## 通常の操作

最初のメッセージに「何をするか」「どこを対象にするか」「入力する内容」を表示します。読んでから、次のいずれかを選びます。

- **今回だけ許可**：今表示されている1回だけ実行します。
- **この依頼中、このツールを許可**：今の依頼が終わるまで、表示した範囲の通常操作を許可します。別の対象や入力でも使われるので、その範囲をカードに記載します。
- **拒否**：今の操作を許可しません。依頼全体を止めたい場合は `/stop` を使います。

メッセージの送信、共有権限の変更、削除などは、その都度確認します。その場合は「今回だけ許可／拒否」の2つを表示します。「今回だけ許可」を押しても、残りの操作まで自動的に許可することはありません。

## 他の参加者に見せない内容

個人情報・連絡先・DMやメール・認証情報・実行コードなどは、元の会話に内容を表示しません。

カードの **「自分だけに表示して確認」** を押すと、依頼した本人にだけ見えるメッセージに内容と許可・拒否を表示します。**同じチャンネルの他の参加者には、そのメッセージは見えません。** 他の人が確認ボタンを押しても、依頼者の内容は表示しません。

確認ボタンを押しただけでは実行されません。内容を読んでから許可・拒否を選びます。DMへ移動する操作ではありません。

元の会話に添える説明：

> この内容は、あなたにだけ表示して確認します。同じチャンネルの他の人には見えません。内容を開いただけでは実行されません。

メールの内容を読む許可と、メールを送信する許可は別です。読む操作に依頼中の許可を出していても、送信や削除は毎回確認します。

長い内容はページを分けて表示します。途中でも拒否できます。許可は、省略のない全ページを表示できた後に選べます。

メールや個人情報用の入力欄に加え、文章中のメールアドレスなども検査します。ただし、普通の文章に紛れた人名や独自の秘密番号まで、すべて自動で見分けられるわけではありません。

## 内容を取得できない場合

「操作内容を取得中」「接続先を確認できませんでした」など、実際の理由を表示します。内容が確認できるまでは許可できません。「再確認」は内容を取り直すだけで、AIへの依頼や操作をもう一度実行するボタンではありません。

この状態を「個人情報があるため」と説明したり、普通の操作まで毎回「自分だけに表示して確認」へ案内したりする動作は、今回の修正で解消する対象です。

## 許可が終わるタイミング

依頼中の許可も永久には続きません。停止・追加の発言・依頼の終了・取消・期限切れ・設定変更・再起動で終了します。次の依頼や別の会話には持ち越しません。許可の一覧と取消は `/mcp` で確認します。

停止と許可取消は役割が違います。許可を取り消すと次の自動許可を止めます。既に始まった作業も止めたい場合は `/stop` を使います。

## Notionの部分置換を実行できない場合

確認してから実行するまでの間に、他の人が本文を編集することがあります。現在の接続方法では、確認した本文と実行時の本文が同じだと保証できません。そのため、部分置換を制限する承認ポリシーを使用する実行では、この操作を実行しません。このポリシーを使用しない他のクライアントへ、禁止設定を自動で適用することはありません。

この場合は理由を表示し、許可ボタンは出しません。「自分だけに表示して確認」を開いたり、以前の許可を使ったりしても実行できません。操作を拒否するか、依頼全体を止めたい場合は `/stop` を使えます。別の編集方法へ勝手に切り替えて実行することもありません。
